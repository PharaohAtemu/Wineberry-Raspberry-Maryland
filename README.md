# Wineberry-Raspberry-Maryland
Application to compare spread of Wineberry (invasive) to Black Raspberry (native) across Maryland Counties from 2016 to early 2026. Data was used from iNaturalist database. 

## To use
Download all files. 
Required libraries: 
* dash
* pandas
* geopandas
* dash_bootstrap_components

(Application was built on VScode.)

Run from app.py
A "How to Use" popup will appear in the localhost. Read that to understand the application data visualizations.
